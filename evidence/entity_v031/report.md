# 实体抽取改进报告：entity-rules-v0.3.1

分类模型为small-intent-v0.1，升级独立确定性实体规则。

## 实体抽取的改进

- 将本人声明与他人转述分别处理，包括“某号向我报告”中容易误认的“我报告”子串。
- 限定否定作用范围，避免“不把票投给某号”被另一条正向规则再次匹配；跟票对象与被投对象分别保留。
- 跨逗号连接查验对象与结果，保留多夜/多目标结果；“上一夜”不猜成第一夜。验人结果不自动复制为怀疑对象。
- 改口后记录当前目标、撤回目标与条件备选；撤回身份/观点/查验不当作撤回投票。
- 附议论据、支持身份、怀疑身份分别抽取；缺少唯一指代时不补编号。拒绝把查询或修改别人正式选票的请求抽为本人意向。
- 保持返回字段兼容，新增实体版本号；Python入口model.predict_v031，HTTP入口model.server_v031。旧入口和旧版本结果保留。

## 验证过程与可解释范围

这是确定性规则的工程迭代。开发使用354条训练数据与语义用例；随后新增72条、再新增36条助手编写的模拟实体样本。初次评分分别暴露问题后，这些样本已经用于修复，最终全部只称为已知回归材料。

中间版本及首次结果完整保留：v0.2首次72条全字段匹配63条（旧版48）；v0.2.1首次36条匹配31条（旧版27）。最终版本在这些已知材料上的高分不能解释为独立泛化成绩。作者与规则开发者相同，没有独立人类标注或真实对局来源。

原120条冻结测试与原50条模拟探针也只作诊断回归，不用它们的新分数替换v0.1分类模型的首次独立留出结果。data/test_frozen.csv等文件及旧模型权重、evidence/evaluation_v01均保持原哈希。最终新版的独立自然对局验证仍为0，待B/C日志。

## 自动化与复现

原完整本地交付包通过91项unittest测试方法，包括历史版本接口、受控错误与本机HTTP往返。本仓库只提供当前版本所需的测试子集。另覆盖50条开发语义用例，以及对同一组场景的300组编号循环置换检查；这些测试不是独立语料评估。

运行最新Python接口：`python -m model.predict_v031 --text "我同意2号的观点，这轮投4号" --speaker-id 1`。启动HTTP：`python -m model.server_v031 --port 8765`。运行当前版本回归用例：`python -m unittest discover -s tests -p "test_a_*.py" -v`。72+36条的历史实验过程保留在原本地交付包，不包含在本次精简上传材料中。

生产字段说明见model/interface.md；规则代码、依赖模块与权重哈希见freeze_manifest.json。历史候选及其全套结果保留在原本地交付包；当前仓库保留原分类快照及最新实体诊断。
