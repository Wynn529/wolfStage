# 狼人杀网页完整操作指南

适用版本：十人局、九模型整合服务前端。更新日期：2026年11月8日。

本指南按当前页面实际功能编写。真人局与全AI观战的可见内容不同；新版服务回放与旧版日志回放的按钮也不同。

## 一、打开网页与认识页面

当前本机离线练习入口：http://127.0.0.1:18517/ 。必须先启动服务，网页才能使用；该地址只能用于这台电脑，同学在自己的电脑点它不会连到你的网页。

页面主要分为：

1. **左上角“展开游戏设置”**：选择席位、身份、模型和服务地址；展开后点“收起设置”腾出展示空间。
2. **顶部“现场对局／历史回放”**：控制当前游戏，或查看已保存过程。
3. **运行按钮和状态提示**：建局、单步、自动、暂停等。
4. **机器人长方桌**：上排1—5号，下排6—10号；中央显示当前行动或发言。
5. **小模型观察站**：展示公开发言的分类及信息提取。
6. **桌面下方的记录区与真人操作区**：往下滚动查看发言、检查记录，并找到“你的回合”。

顶部出现“九模型接口离线联调”时，机器人使用固定测试逻辑，名牌只表示配置的型号，不表示真实模型已调用。当前离线练习不产生API费用。

## 二、左侧游戏设置：每个选项怎么用

| 选项 | 用法与含义 |
|---|---|
| 随机种子 seed | 决定可重复的身份分配及部分规则裁决；相同种子和配置通常得到相同初始分配。真实模型的发言不保证逐字相同。练习时可保留42。 |
| 对局模式：全AI | 十个玩家都由程序控制，你负责观看和运行控制。 |
| 对局模式：真人参与 | 你控制一个席位，其余九席由AI控制；当前支持一名真人。 |
| 真人席位 | 选你坐几号，范围1—10；全AI模式下不可选。 |
| 真人身份（新局生效） | 选择随机、狼人、预言家、女巫、猎人或平民；只在点击“开始对局”建立新局时生效，不会改变已经开始的对局。 |
| B服务地址 | 后端游戏服务的地址。离线新版练习目前为18085；团队真实整合服务默认18083。按启动窗口提供的地址填写，不要填供应商API地址或密钥。 |
| AI默认模型 | 从服务端登记列表选择全部AI的初始型号；“已登记”不代表本场已成功调用。 |
| 统一后逐席调整 | 先以默认型号填入AI席位，再展开下方设置调整个别席位。 |
| 按登记列表轮流分配 | 按服务返回顺序为AI席位轮流分配型号；有九个型号、九个AI时可各用一个。 |
| 逐席位模型设置 | 展开后逐个修改AI席位型号；同一型号允许重复，真人席位不选择模型。 |
| 本机控制记录 | 选择此前的控制记录，用来查询某一局和操作的执行结果；不是聊天记录，也不是API账单。 |
| 恢复记录（只读查询，不重发） | 按原局号与操作编号查询恢复，不重新发送旧操作；须匹配当前服务及契约，当前会话还需具备该真人局的权限。 |

建议顺序：先选模式 → 真人席位和身份 → 模型分配 → 核对页面“新局设置” → 开始对局。

切换分配方式或默认型号时，应再检查逐席配置；已有局仍使用建局时固定的配置。

“契约”“适配版本”等文字主要用于联调定位问题，普通玩家不需要填写。若真人会话已丢失，恢复按钮不能绕过鉴权找回私密信息。

## 三、运行按钮：每个按钮做什么

| 按钮 | 功能 |
|---|---|
| 开始对局 | 根据左侧设置创建新局、分配身份；已有局的原始记录保留。建局本身不调用付费模型。不要把它当作继续当前局。 |
| 单步推进 | 推进一个业务步骤；一步可能产生多条事件，也可能包含模型调用和分类。点完等待完成。 |
| 自动运行 | 连续安排下一步；遇到真人回合、失败、终局等情况会停止。真实准备模式中此按钮可能被禁用。 |
| 停止自动调度 | 不再自动安排下一步；已经发出的请求仍要等待完成。 |
| 暂停 | 申请暂停对局；当前一步正在执行时，会等它结束，不能取消已发出的模型请求。 |
| 继续 | 解除已暂停状态；之后自行选择单步或重新开启自动运行。 |
| 重试当前席位 | 新版服务确认当前模型请求超时后出现。在原局重试这次行动，保留之前的发言、行动和已封存的票。每次点击会重新请求一次模型，可能产生费用。 |
| 刷新事件 | 只查询已有状态和事件，不开始新行动，不额外请求玩家模型。日常优先使用它。 |

按钮变灰通常是因为：请求尚未结束、轮到真人、已经暂停或结束、操作结果未确认，或者当前模式不允许该操作。先看按钮附近的状态提示。

“等待模型”表示本步处理中；“等待真人”表示要到下方输入；“已暂停”要点继续。达到上限而结束不等于某一方获胜。

真实服务的单步推进可能计费，一次点击也可能包含多次请求；当前离线练习的自动运行和真人操作不产生API费用。

## 四、真人在哪里行动、在哪里输入

**往下滚到“你的回合 · ×号玩家”。这个区域只在轮到你时出现。左侧游戏设置不是发言输入区。**

1. 查看本人身份、当前阶段和提示。
2. 选择行动或输入文字；需要目标时再选择“目标席位”。
3. 点“提交真人操作”，等待返回，不要重复点击。
4. 成功后选择单步或自动运行，等待下一次轮到自己。

公开发言、遗言和狼队讨论都支持中文，不要求使用英文；真人不需要填写决策依据。

如果提交结果不明，页面会只读查询原操作编号，并锁定重复操作。不要重新建局或反复提交来试探是否成功。

### 1. 所有存活角色共有的白天操作

- **公开发言**：轮到自己时，在“公开发言”大框输入中文，再点提交。内容进入所有玩家可见的发言记录，并由小模型分析。
- **投票**：从合法目标中选择玩家后提交；需要弃票时选择“放弃／弃票”。不要在发言框里只写“我投2号”就当作完成正式投票。
- **遗言**：系统允许发表遗言时出现“遗言”输入框；输入后提交。不是所有死亡方式都一定有遗言机会，以系统阶段为准。

### 2. 狼人

- 夜间选择“狼人击杀提案”，选择合法击杀目标后提交；不能选择狼队友。
- 可在“狼队讨论”中写文字，也可留空；当前新版随击杀提案一起提交，没有独立发送讨论的按钮。
- 本人区域会提供自己有权知道的队友信息；讨论不作为全场公开发言。
- 白天与其他角色一样发言、投票，可以选择怎样陈述自己的身份。

### 3. 预言家

- 夜间选择“预言家查验”，选择合法目标并提交；本人、死亡者和已查验目标按后端规则排除。
- 结果只向本人等有权限的视角显示。`good`表示好人阵营，`wolf`表示狼人，不是查出对方具体好人神职。
- 页面提供放弃选项时可以选择放弃。
- 白天可在公开发言中报告查验，也可选择暂时保留；报查验不等于再次使用技能。

### 4. 女巫

- 根据本人可见信息，在“行动”中选择使用解药、使用毒药或放弃。
- **解药**救当前夜间刀口，不另外选目标。
- **毒药**需要从合法目标中选择玩家。
- 两种药各一次，每晚最多使用一种；首夜以外不能自救。不可用的药剂不会作为可执行选项出现。
- 白天正常发言、投票。

### 5. 猎人

- 平常没有夜间主动技能，白天正常发言、投票。
- 被狼杀或被放逐且具备开枪资格时，才会出现“猎人开枪／放弃”。
- 选择开枪时还需选目标，再提交；不想开枪可放弃。
- 被毒死不能开枪；刀毒同时命中按毒死处理。后续遗言按系统提示进行。

### 6. 平民

- 夜间没有技能，不用填写任何内容，等待其他角色完成行动。
- 白天轮到自己时输入公开发言，投票阶段选择目标或弃票。

## 五、怎样看机器人桌面

| 画面 | 含义 |
|---|---|
| 上排1—5号、下排6—10号 | 玩家席位，编号固定。 |
| 机器人下方型号名牌 | 建局时配置的模型；仍需结合调用记录确认真实执行来源。 |
| “我”与“真人” | 你控制的席位。 |
| 身份卡 | 真人模式只显示本人有权知道的身份；其他人写“玩家”是权限保护。 |
| 当前行动人发光 | 当前正在行动或等待操作的席位。 |
| 目标框、连线 | 当前事件涉及的目标，不等于该目标已经死亡。 |
| 身体灰色、已出局 | 服务记录显示该玩家已出局。 |
| 夜间变暗、白天变亮 | 当前游戏阶段。 |
| 中央聊天框 | 当前行动、具体公开发言、等待或结果提示；行动与发言使用不同框形。 |
| game_id、event_id | 对局编号与事件编号，供回放、截图和排错定位；事件编号不是轮数。 |

真人出局后也不能立即查看其他人的秘密；要等对局结束，再按权限打开终局回放。

## 六、小模型观察站与依据区域

小模型观察站随公开发言显示：原句、意图分类、提及玩家、身份声明、查验／投票目标等提取信息，以及模型版本和记录状态。

- 分类描述的是“说了什么”，不是认证玩家身份或判断发言真假。
- 技能宣称（`skill_claims`）是从发言中提取的线索，不代表技能真的执行。
- 分数未校准，不当作正确率或概率。
- 夜间没有公开发言时，显示等待分析是正常情况；当前动作与最近一条已分类发言可能不是同一事件。
- “查看本步证据”可展开当前组件收到的事件、分析和统计，用于对照，不会重新运行模型。

“角色自述依据”是AI解释自己为什么行动；它可能包含猜测或伪装，不是可验证的内部思考，也不是真相证明。宽依据区域可展开／收起；只显示当前视角获准查看的内容，真人自己的操作不生成虚构依据。

## 七、公开发言记录（所有玩家）

点击标题可以展开或收起；默认展开。这里按顺序保留已经发生的公开发言和公开遗言，并标明第几天、几号、发言还是遗言。

可在此回看前面的人说过什么，再决定自己的发言和投票。夜间查验、狼队秘密讨论和私密决策理由不会混进公开发言记录。

没有记录时先看当前是否仍为夜间；历史回放只显示进度条之前的内容，不提前显示后面的发言。

## 八、身份总览与AI依据详情

全AI观战或获准的终局回放中，页面可能出现以下折叠区；真人进行中隐藏这些上帝信息是正常的。

- **身份总览（主持视角）**：查看当前已授权事件中的身份和存活情况，不提前读取未来死亡。
- **AI依据详情 · 完整原文与技能线索**：按玩家、阶段和对应事件查看已记录的AI依据、模型记录及技能宣称；原件没有型号或依据时会提示未提供。

普通真人发言不必打开这些区域；自己的私密结果在本人可见事件或行动结果中查看。

## 九、检查记录：四个标签页分别是什么

点击 **“检查记录 · 完整事件 / 投票原件 / 调用统计”** 展开。这里的“完整”只指当前视角、当前回放进度已获准显示的记录，不会绕过真人权限。

### 1. 公开事件与分类

查看公开行动经过和每条发言对应的小模型标签、实体、版本及事件原件；可核对网页有没有漏显示、分类是否对应同一句话。JSON是结构化记录，可以展开查看，不需要编辑。

### 2. 投票与结果

新版投票在收齐选票前保密，计票后主页面统一公布每位存活玩家的得票数、弃权人数和放逐结果。十人局最高票平票或全员弃权时无人出局。“投票与结果”保留各轮计票原件；旧回放仍可查看原有逐票记录。

公开发言中的“我要投2号”只是意向。真人需在“你的回合”提交投票或弃票。

### 3. 仅上帝视角

用于获准的观察者查看私密事件和AI自述依据；真人进行中不会显示其他人的秘密，出局后也一样。

### 4. 统计与原始事件

查看服务返回的调用统计，以及当前已显示事件的JSON。一次请求尝试单独计数，重试也计数；未知token不等于0，调用次数不能直接换算费用。真人动作不算玩家模型调用。

新版真人进行中会限制原始调用和逐席统计。旧版同机模式可能额外显示原始调用重算及逐席表；新版不保证提供相同明细。

“下载当前已显示事件（查询副本）”下载的是当前可见记录，不是服务器所有原始文件，也不包含未来事件或应隐藏的秘密。

## 十、历史回放：新版与旧版要分开使用

### 新版服务回放

1. 顶部选择“历史回放”，回放来源选择“新版服务”。
2. 输入要查看的对局编号；当前局编号会自动带入。
3. 拖动“回放到event_id”查看对应位置。

当前新版使用进度条手动回看，**没有播放／暂停回放按钮**。读取回放不调用玩家模型。未结束真人局会被服务拒绝，这是权限保护；不会回退读取本机原始日志。新版暂不提供原始日志包下载。

### 旧版日志回放

1. 选择“旧版日志（历史六人局）”。
2. 从本地对局列表选择一局，拖动事件进度条。
3. 可点“播放回放”“暂停回放”；到末尾可“重新播放”。
4. 展开“回放文件与导出”，可查看局号和事件号，并导出B原始日志包。

旧版回放只读已保存记录，不重新调用模型；“下载原始包”和“下载已显示事件副本”不是同一种材料。没有本地日志时列表为空，不表示后台能自动取得其他电脑的记录。

## 十一、常见情况怎么处理

| 情况 | 先怎么做 |
|---|---|
| 找不到设置 | 点左上角绿色“展开游戏设置”。 |
| 找不到发言框 | 确认已经轮到真人白天发言，再向下滚到“你的回合”；夜间不会一直显示公开发言框。 |
| 身份选择后没变化 | 侧栏是新局配置，已有局不变；先核对设置，再点开始建立新局。 |
| 自动运行停了 | 看是否轮到真人、已暂停、失败或结束；真人提交后重新开启自动运行。 |
| 1号离线玩家首夜出局 | 离线狼人优先攻击最小编号非狼人，女巫默认不救人；这不是模型策略成绩。练习可换席位或种子。 |
| 查验结果显示good | 表示好人阵营，不表示平民或某个具体神职。 |
| 重复点击后不推进 | 可能在等原操作结果，先刷新事件／查询，不要另建局或反复提交。 |
| 后端确认模型请求超时 | 等原操作结果核对完成后，点“重试当前席位”。成功后继续单步推进；离线预览也可重新开启自动运行。 |
| 重试期间服务中断 | 重启后刷新事件。已入账的行动会恢复；页面若提示“重试期间服务中断”，可手动再次重试。上一次请求可能已产生费用。 |
| 普通模型请求期间服务中断 | 重启后刷新事件。服务会继续入账已经保存的行动。若页面提示“模型请求期间服务中断”，可手动重试该席位；上一次请求可能已产生费用。 |
| 看到模型失败或原始错误入口 | 保留局号、事件号和错误截图；失败记录不会被当成成功对局。 |
| 真人回放提示不可用 | 等对局结束；不要通过改URL或换玩家编号绕过权限。 |
| 浏览器关闭／强制刷新后无法恢复真人局 | 会话凭据只在网页服务端内存中，可能已经丢失；控制记录不是凭据，不能保证找回。保留原局记录，再安排新练习。 |
| 网页所有按钮不可用或打不开 | 检查启动窗口和服务是否仍运行，不要先反复点击开始或提交。 |

## 十二、启动与演示前检查

离线练习：在已配置的Python环境、仓库根目录运行 `python scripts/start_c_integration_ui.py --offline-preview`，按输出打开网页。本机另有“启动C九模型离线预览.cmd”快捷入口；端口已占用时先查看现有网页，不重复启动。

真实模式：先按团队整合说明启动模型服务，再运行 `python scripts/start_c_integration_ui.py --connect-real --service-url http://127.0.0.1:18083`。网页不收集供应商密钥，启动不自动请求模型；真实准备模式关闭自动运行。正式付费联调需先确认额度和九家累计费用保护。

演示前确认：使用同一版程序、服务已启动、明确离线还是真实、能找到设置和真人输入区、准备好对局编号。录屏时说明现场还是回放；九家各一次接口测试和离线练习都不能冒充真实完整九模型对局。
