## 场景版呈现（C v0.4）

主页面约2/3为六机器人圆桌场景，约1/3为同步小模型分析。原创SVG机器人、发牌身份动画、昼夜背景、行动与发言两类气泡和出局灰色状态由当前已接收事件驱动。无事件时身份未知；回放仅投影当前前缀，不提前显示未来死亡、分类或胜方；回放播放按钮只移动日志游标，不推进游戏或请求模型。夜间行动标识仅供上帝视角，详细事件和统计收进检查区。

## 本轮C控制适配范围

### 投票与终局展示

C页面增加“投票与结果”分区：按已显示的公开事件顺序分组列出逐票记录，票数只展示B的vote_tally原件，放逐只依据exile事件，胜方只依据game_over。缺少valid、计票或目标时明确标未提供/等待，不在前端补算或修正规则；回放仅使用当前游标前缀，未来票数/死亡/终局不提前显示。公开事件采用中文说明并保留原始记录入口；私密动作与角色自述依据继续置于上帝视角。

C实现业务操作ID、同会话单次提交、后台控制请求、只读轮询、等待/暂停申请显示、超时后按操作查询恢复、终态停机、增量去重和统计核对。现有B维持legacy模式，自动功能继续锁定；参考控制契约在docs/c_control_contract.md中单独说明，未冒称B已实现。只有提供已确认契约且实际状态查询验证成功，页面才允许自动运行。参考服务仅用于测试，不混入真实对局证据。B源码/协议保持不变。

本分支开发 C 的 Streamlit 网页，复用 A 的8765分类服务和 B 的8000游戏服务；网页端口8501。先使用离线玩家与真实本地分类模型，界面明确标注来源。真实 DeepSeek 验收另行进行。

入口为 app/ui.py，服务请求集中于 app/ui_client.py，事件投影及只读日志操作集中于 app/ui_helpers.py。UI 不修改 B 的规则、胜负、原始日志或角色输入。当前自动推进暂不开放：B 尚未提供重复提交/并发推进保障。网络超时后先刷新，不自动重试控制请求。

环境安装：Python3.12，依次安装 requirements.txt、model/requirements.txt、requirements-ui.txt。A入口：python -m model.server_v031 --port 8765；B入口：python -m uvicorn app.api:app --host 127.0.0.1 --port 8000；C入口：python -m streamlit run app/ui.py --server.address 127.0.0.1 --server.port 8501。

本地只读日志方案：页面从仓库 runs/ 下读取对局列表与原始日志；回放与导出不请求模型。此方式只适用于 A/B/C 在同一台电脑运行，远程部署需 B 补对应接口。导出保留原始文件字节，不将页面筛选结果当成原始日志。

验收前提：B 已知的 reason 隔离、狼队友击杀、协商、重投、用量和重试记录缺陷仍须由 B 修复；本分支界面不掩盖这些问题。当前只能称为接口联调基线。

## B 3898b95 复验适配

启动脚本设置 `C_B_REVISION=3898b95`，使用 `BRevisionClient`；只对 advance 发送操作编号并查询完成结果。unknown 不解释为未执行；pause/resume 仍无查询保证，自动运行继续锁定。新私密理由关联展示，不覆盖公开发言气泡。验收及遗留项见 `evidence/c_b_update_acceptance.md`，本轮72通过、8已知缺陷预期失败，不修改B实现。

## C 顺序自动推进与排队暂停

针对 B 3898b95，C 可以在本会话内等待每个 advance 的操作查询完成、HTTP请求结束且游标同步后，再调度下一步。暂停先停止本地调度，若有在途步骤则排队，整步确认完成后才向 B 发送 pause；不在 B 的慢调用期间发送 pause。此方案只保障本页面调度，不宣称 B 的跨会话暂停/多进程契约已修复，B 原问题继续保留。unknown/超时不重发，失败停止；继续解除暂停后不暗中开启自动。等待是状态，不是按钮；页面直接显示等待/待暂停/已暂停及不可用原因。

## C 易用性收尾（2026-10-29）

主页面增加可折叠的新手说明、当前局编号及下一步提示；保持原按钮、控制语义、真实模式自动禁用和回放只读。等待提示说明当前一步仍在处理、不能重复提交；暂停/继续分别解释何时生效及是否会产生下一步。

失败信息依据B当前事件解释：明确的 action/target/text/reason 规则校验错误展示“行动格式未通过规则检查”；传输/鉴权错误与未知错误不冒称模型已正常返回。分类失败单独提示，不伪造分类、不将其默认归为B模型请求失败。场景和页面使用同一解释，保留原始错误入口，不改事件或B状态。

统计表展示中文表头，明确“调用尝试包含重试”“B记录通过不等于HTTP返回成功”“token未提供不等于0”“计数不是金额/正确率”。回放继续只展示已选前缀，不从未来事件取得失败原因或整局统计。核对使用已保存的真实失败局和离线测试，不新增付费请求。
