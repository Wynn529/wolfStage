## 启动和使用（2026-11-08）

在已安装requirements、requirements-ui及model/requirements的Python环境，仓库根目录运行：

```powershell
python scripts/start_c_integration_ui.py --offline-preview
```

打开http://127.0.0.1:18517/，服务为18085。离线后端只使用PreviewAgent，九家登记型号用于检查配置，模型行动不算真实调用；日志单独保存在.local/c_integration_preview_runs。该模式不需要Key，启动器移除九家Key后再启动子进程。

真人参与：选席位和身份，选择“按登记列表轮流分配”即可为九个AI配置九个型号，也可统一后逐席覆盖。点击开始、确认本人身份，自动运行遇到真人回合会停止；向下滚动到“你的回合”提交操作，之后可重新选择单步或自动运行。自己的身份卡可见，其他人身份隐藏。

对接已由文斓启动的新真实服务时：

```powershell
python scripts/start_c_integration_ui.py --connect-real --service-url http://127.0.0.1:18083
```

此命令只启动网页，不输入或保存供应商密钥，不自动建局/推进，真实准备模式自动运行关闭。九家累计额度保护与真实完整局尚未验收；本次未启动此模式。不得用旧1元DeepSeek账本推断九家费用均已受控。

新版回放填写game_id，走新服务/replay；未结束真人局收到403后不会回退读取本机文件。旧六人回放使用“旧版日志”入口。新版暂不导出原始调用包。页面内刷新与控制记录恢复复用当前服务端会话；关闭或强制重载浏览器导致会话丢失时会清除缓存并拒绝恢复私密数据，令牌不保存在本机日志或URL。
