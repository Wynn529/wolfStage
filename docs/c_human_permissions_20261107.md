# 本机单真人权限契约

本轮按新版方案保护本机单真人流程，不建设远程多用户账号系统，不抵御本机用户直接打开服务器文件。服务端以建局冻结的唯一真人席位确定玩家身份，不相信view/player_id用于提权；多真人配置拒绝。真人进行中（包括已出局、暂停和失败）只提供公开及本人允许知道的事件，本人身份/合法动作独立接口；god/host不提升权限。全AI观战可看上帝信息，真人局finished或incomplete结束后才开放完整回放和统计。

进行中真人局禁用/replay、原始本机回放及导出，状态/操作回执/统计不含其他角色原始调用详情。前端恢复先读取服务端席位信息，清除不属于本人可见范围的缓存；详情不读取本机原始调用，不能把秘密藏在折叠区。目录列表和直接game查询同样拦截，历史旧六人全AI继续只读。

此契约是单真人共享本机应用的服务端视角约束，不声称支持多账号身份认证。真实多用户远程接入需另加身份认证，不通过传player_id冒充实现。
