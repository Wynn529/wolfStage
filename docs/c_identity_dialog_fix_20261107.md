# 真人身份确认弹窗修复

真人建局时，身份弹窗从每0.5秒刷新的现场fragment内部打开；弹窗自身也是fragment，两个刷新生命周期嵌套导致确认后仍可能收到已经失效的fragment请求。

将身份弹窗移到整页层级。真人建局成功后先整页刷新，再由顶层打开弹窗，现场定时刷新不再创建或重新注册弹窗；确认只记录当前game_id并整页刷新，不重新建局，不推进游戏，也不调用模型。

验证真人建局、身份确认、确认后持续等待与操作；同时复查权限和建局次数。

身份确认后场景组件按对局ID及确认状态重新挂载一次，避免弹窗关闭后同参数组件残留空白；正常定时刷新继续复用组件。真人权限及身份确认专项32项通过，确认前后game_id、事件游标不变。
