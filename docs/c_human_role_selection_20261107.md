# 真人身份选择核对

将“随机/指定”与单独角色框合为一个选择框，选项包含随机、狼人、预言家、女巫、猎人、平民；在开始按钮上方明确显示本次建局配置，选择只对新局生效。确认弹窗以服务端返回身份为准，已有局的角色不随侧栏设置改变。

对五种指定身份执行网页建局到确认的HTTP联调，核对服务端角色、弹窗和十人角色总量。随机模式同一种子及席位可重复，不承诺每次得到不同角色。

离线StubAgent固定选择编号最小的非狼人作为夜杀目标，女巫默认不救人，因此1号平民可能首夜死亡；保留该测试规则，不加入真人免死或伪装成真实模型策略。在离线预览明确标注这一限制。

结果：37项权限和身份检查通过，五种指定角色的服务端值与弹窗一致；浏览器已确认预言家身份。当前示例局0a02866ac29c未推进。
